KOD MIRZE – iPad-Kassenprototyp

1. ZIP entpacken.
2. index.html auf dem iPad in Safari öffnen (z. B. über Dateien/iCloud Drive oder eine eigene Webadresse).
3. In Safari: Teilen > Zum Home-Bildschirm.

WICHTIG:
Dies ist nur ein technischer Prototyp. Er ist keine TSE-Kasse und keine steuerlich freigegebene offene Ladenkasse.
Nicht als alleinige steuerliche Aufzeichnung oder für den echten Geschäftsbetrieb verwenden, bevor ein Steuerberater die konkrete Nutzung geprüft hat.
Daten werden nur lokal im Browser gespeichert. Regelmäßig CSV und JSON exportieren.
